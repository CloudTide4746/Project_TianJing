  Demo体验流

  评委看到你打开App，对准兵马俑一号坑拍照。

  屏幕显示原片。
  然后——

  原片开始"裂开"。

  石头纹理从中间蔓延，
  表层碎裂、剥落，
  灰尘粒子散开——

  一张秦代风格的藏品从原片底下"被挖出来"。

  不是覆盖。不是替换。
  是"原本就藏在里面"。

  最终卡片上：
    秦·兵马俑一号坑
    坐标：34.3852°N 109.2731°E
    在场时间：2026.05.23 14:37
    天气：晴 28°C
    在场序列：第37位
    一行文："你站在这的时候，他们已经站了2200年。"

  ---
  为什么这跟朋友圈不一样

  朋友圈做的事：你拍一张，你发一张。它是发布。
  这个App做的事：你拍一张，它从里面挖掘出一件"时间在你照片里提前埋好的文物"。

  ┌──────────────┬──────────────────┬────────────────────────────────┐
  │              │      朋友圈      │            在场考古            │
  ├──────────────┼──────────────────┼────────────────────────────────┤
  │ 动作         │ 发布动态         │ 挖掘文物                       │
  ├──────────────┼──────────────────┼────────────────────────────────┤
  │ 结果         │ 时间线上的一个点 │ 藏品库里的一件藏品             │
  ├──────────────┼──────────────────┼────────────────────────────────┤
  │ 回溯         │ 滚不到底         │ 地图+时间轴随时检索            │
  ├──────────────┼──────────────────┼────────────────────────────────┤
  │ 与他人的关系 │ 点赞评论         │ 沉默的在场序列                 │
  ├──────────────┼──────────────────┼────────────────────────────────┤
  │ 视觉         │ 原图             │ AI根据地点气质翻译后的"文物图" │
  ├──────────────┼──────────────────┼────────────────────────────────┤
  │ 核心理念     │ "我去了这"       │ "这一刻值得被存档"             │
  └──────────────┴──────────────────┴────────────────────────────────┘

  ---
  评委3秒就能get的钩子

  你一边演示一边说：

  ▎ "每个人都在朋友圈发'我去过了'。
  ▎ 我们做的事正相反——
  ▎ 我们问：你去过的这个时刻，1000年后还值得被看见吗？
  ▎ 如果值得——我们就帮你把它从时间里挖出来。"

  ---
  48h MVP

  T1 必做：
    - 拍照/选照片
    - 获取GPS+时间戳+天气
    - "挖掘"动画（3层：裂纹→剥落→灰尘→揭示）
    - AI风格化藏品图（至少3种地点气质模版）
    - 时空卡（含全部锚定数据）
    - 藏品库（网格+时间轴两种视图）

  T2 加分：
    - 一行金句（AI根据地点生成）
    - 在场序列号（同一地点计数器）
    - 分享卡片（带二维码回流）

  T3 锦上添花：
    - 地图视图
    - 地点气质自动识别→匹配风格

  ---
  你现在的三个武器

  1. 「挖掘」动画 → 演示感。这是拿奖的第一武器。
  2. 时空锚定数据 → 厚度。不是一张图，是一份在场证明。
  3. "在场序列" → 记忆点。"第37位"这个数字本身就是一个故事。
